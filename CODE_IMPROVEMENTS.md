# Build Roadmap

## Current Baseline

- Founder-first ERP shell
- Legal knowledge injection workflow
- AI-oriented export layer
- CSV bulk import support
- Version snapshots for core legal content
- Knowledge graph relation mapping

## Recommended Phase 2

- CRUD screens for `revision_tasks` and `mock_attempts`
- Per-user progress tracking
- Dashboard filters by subject and exam paper
- Saved export jobs and background processing
- Search across full corpus with highlights

## Recommended Phase 3

- Role-based authentication
- Student portal
- Corporate compliance dashboard with alerts
- Task assignment and audit logs
- API endpoints for mobile or SaaS clients

## Recommended Phase 4

- Embedding pipeline
- RAG retrieval console
- Fine-tuning dataset templates by use case
- PDF OCR / parser integration
- Amendment comparison and automated diffing
